Python Conditionals Practice

A collection of beginner Python programs that practice user input, arithmetic, and if / elif / else logic. Each program runs in the terminal and prompts for input.

Programs
#	Program	Description
1	Positive / Negative / Zero	Reads an integer and reports whether it is positive, negative, or zero.
2	Marks & Grade Calculator	Takes marks for Physics, Chemistry, Biology, Mathematics, and Computer (out of 100 each), computes the percentage, and assigns a grade.
3	Triangle Type Checker	Takes three side lengths and classifies the triangle as equilateral, isosceles, or scalene.
4	Login Check	Compares an email and password against stored credentials and reports which (if any) is wrong.
5	Leap Year Checker	Determines whether a given year is a leap year.
6	Greeting	Asks for your name and greets you.
7	Square of a Number	Reads a number and prints its square.
8	Area of a Triangle	Reads base and height and prints the area (0.5 * base * height).
Grading Scale (Program 2)
Percentage	Grade

Leap Year Rule (Program 5)

A year is a leap year if it is divisible by 4 and not by 100, or if it is divisible by 400.
